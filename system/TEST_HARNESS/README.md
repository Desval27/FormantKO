# MODULE TEST BOARD

The **Test Board** is a bench-top development, calibration, and diagnostic tool for Formant modules. It provides a single backplane bus connector with convenient access to all bus signals, allowing individual modules to be powered, calibrated, and tested without being installed in a complete synthesizer system.

The board accepts power from a laboratory bench supply via banana jacks and includes LED indicators for the power rails and GATE bus states. All bus signals are brought out through jumper headers for easy monitoring, isolation, or external connection. Built-in pushbuttons allow manual injection of GATE signals, while selectable potentiometers and switches provide adjustable KOV/CV test voltages for functional testing and calibration. This makes it possible to verify module operation, perform adjustments, and troubleshoot faults entirely on the workbench before installation in a Formant cabinet.
